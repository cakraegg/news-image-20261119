# news-image-20261119 — "The World in One Day"

One image that sums up the world news of Thursday 19 November 2026:

- **Grand Theft Auto VI launches worldwide** — Vice City opens after a 13-year wait
- **Gulf on edge** — the US and Iran trade fire again in the Gulf
- **A first for the House** — House Democrats nominate Hakeem Jeffries for Speaker, 251–11
- **Nvidia chief quits** — Huang resigns; the acting chief promises earlier pay rises
- **Voyager 1, a light-day out** — NASA set to confirm the probe's milestone

The photographs are AI illustrations made for this entry; the headlines
are set in type from the day's reporting. `main.py` (Python 3.13,
standard library only) copies `entry.png` to `/output/entry.png` and
verifies it is a complete JPEG under the 1 MiB limit, so two runs write
identical bytes.
